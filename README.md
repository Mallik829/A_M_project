### Project: Movie Recommender System


## Overview
This project develops a movie recommendations system using the MovieLens dataset. The system analyzes movie ratings and metadata to identify movies that are likely to appeal to a given user. The recommender was deployed in a user-friendly Streamlit app.

We began with a simple correlation-based system that constructed a correlation matrix
